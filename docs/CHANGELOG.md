# 变更记录

## 0.3.0 — 2026-11-13

状态：待真机验收的发布候选版；未公开部署。

- 五页共用紫灰 / 奶白 / 珊瑚主题，改善窄屏卡片、底部导航和日历约 44px 点击区。
- 首页快速开始 / 确认结束经期，保留完整记录编辑；经期和身体记录使用可滚动弹层，Web 日期输入、可视视口与键盘空间适配。
- 后台读取失败保留已加载数据；广播失败不误报提交失败；草稿固定 revision，避免后台回读后覆盖其他窗口的新记录。
- 清除本机记录入口和隐私说明，清除后销毁已有草稿；不删除下载文件或日历副本。
- JSON 备份升级为 schema 3：应用版本、导出时间、经期、日志、偏好和未加密标记；兼容 v1/v2，预览覆盖确认、原子恢复、未知版本拒绝。
- IndexedDB 未知旧结构中止升级，不创建空库冒充成功；配额、失败回滚、数据库升级与 Store 状态补充回归测试。
- 未结束经期只把开始日视作已确认；排卵经验窗口随日期不确定性扩大，日期上界安全处理。保留原中位数算法、异常间隔披露、逾期不虚构新周期。
- Worker 完整资源 SHA-256 核验、旧版不可变资源离线读取、无自动旧缓存删除；worker 模板变化也改变缓存版本。离线时仍初始化已有注册的更新监听。
- 生产 CSP 与本地响应头验证、防私人文件误打包检查、可复现 ZIP 命令与发布 / 回滚文档。
- 保留四类 ICS、提醒时间和隐私文案；增加重复导出提示。未实现真正 iOS 本地通知。
- Git 初始化检查点；修正旧 ignore 规则误排除首页源码的问题，未删除 V0.2 功能。
