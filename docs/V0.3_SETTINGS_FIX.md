# V0.3 设置与生产启动修复 — 2026-11-15

## 复现与证据

本地隔离来源 localhost:4197 / 4198 / 4199，未操作用户原有来源、未删除数据库。线上地址 cyclemoon-test.zhangyujiayui.workers.dev 经浏览器、HTTP 和另一读取工具访问均失败；本机 DNS 解析到 31.13.94.23，连接未成功。不能据此断言线上 IndexedDB 损坏，也不能确认线上故障唯一原因。

复现了两个可修复的生产缺陷：

1. 旧静态包包含构建当天日期，访问日期变化后出现 React hydration 错误 #418。静态 HTML 可见并不意味着客户端初始化正常；原“本地数据尚未就绪”也是未初始化状态的服务端文案，不是数据库损坏证明。
2. Web 日期输入显示 2026-11-05 / 2026-11-09，提交后实际记录却为当天且未结束。仅监听 change 未同步本次输入事件；补充 input 监听后同一操作实际保存正确日期。

## 修改

- RootLayout 使用 useSyncExternalStore 的服务端 false / 客户端 true 快照，在 hydration 后再渲染日期相关页面，静态页面只显示稳定的启动提示。保留原始本地加载逻辑、导航和 IndexedDB 结构。
- Web 日期控件同步 input 与 change 事件，不改变原生控件、校验或持久化协议。
- 生产检查新增静态外壳必须含稳定启动提示且不能冻结日期的断言。
- 没有删除、重建或迁移用户数据库，没有变更用户默认记录，没有关闭 CSP。
