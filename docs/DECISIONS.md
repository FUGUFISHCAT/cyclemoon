# 重要设计决策

## 001 · 保留 Expo SDK 58 与原生工程

2026-11-12 初始化稳定模板。0.2.0 继续使用通过 Expo 兼容性检查的依赖，不更换为独立网页项目。

## 002 · PWA 作为当前 iPhone 分发

2026-11-13：用户仅有 Windows，当前不购买 Apple 会员。采用静态 HTTPS + Safari 主屏幕，用户免费 Pages 账户自行部署。本次不发布、不上传健康记录。EAS 配置留作未来，不代表当前可免费安装 IPA。

## 003 · IndexedDB 原子快照与统一 Repository

单用户、少量离线健康数据使用版本化快照事务，便于完整校验、恢复和跨平台迁移。1 MB 本地容量上限防止备份无法回读；达到上限拒绝写入，不裁剪历史。
revision 乐观并发控制；未知版本显式失败，绝不删库重建。原生未实现时明确报错。

## 004 · 静态外壳与数据分离

内容哈希缓存版本，新版完整下载后等待应用；不强刷当前编辑。旧窗口存在时保留旧外壳，单窗口新页面再清理；SW 从不访问 IndexedDB，也不缓存运行时健康数据。
用户记录不进入公开 public / dist 或导航 URL。数据备份不属于部署产物。

## 005 · ICS 一次性提醒

不用 PWA 承诺 iOS 本地通知。ICS VALARM 用日历客户端支持的标准格式，浮动本地时间便于个人日程；明确跨时区和导入行为需核对。UID 稳定但不承诺客户端去重，修改后用户自行更新旧副本。

## 006 · 预测诚实表达

有效历史中位数 / 用户初始参数，仅为日历经验估计；展示经验日期范围及数据基础，不给伪造准确率。逾期不自动假定经期已发生，排卵附近不能用于避孕。

## 007 · 加密与隐私

当前 IndexedDB 与导出文件无应用级加密。默认隐私文案不隐藏日期或加密日历。申请持久存储不保证永不丢失，始终支持用户备份。未来 SQLCipher、系统密钥与原生通知需真实实现和验收。

## 008 · 原创图标与可维护视觉

月相符号由仓库 SVG / 几何图形生成 PNG：180、192、512、1024 及 maskable 512，不复制其他健康 App 品牌。保留统一 tokens、系统主题、可访问标签和文字 / 形状标记。
