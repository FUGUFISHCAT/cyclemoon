# 月相 Cycle 0.2.0 产品需求

## 当前交付目标

Windows 开发，iPhone Safari 添加主屏幕，本地优先，零 Apple 会员成本，无 IPA 侧载、无 App Store。免费 HTTPS 静态部署由用户执行，本次不部署。

## 当前功能

- 五页导航：首页周期日 / 估计 / 下一条待导出提醒；日历跨月与真实 / 预计 / 身体记录文字标记；经期与身体状态增删改；洞察展示实际间隔与不确定性；设置参数、提醒、备份、恢复及更新状态。
- 所有真实健康数据存 IndexedDB；无账户、广告、分析或云同步。原生 SQLite 预留，不能用内存假装成功。
- 估计使用有效历史中位数或用户保存的参数；不伪造准确率，不把预测用于避孕。逾期不自动滚动。
- 四类日程：预计开始、前三天准备、预计开始次日确认、记录结束确认。配置本地时间与隐私文案，导出带提醒的 ICS。
- ICS 导入后不自动更新，实际提醒由日历账户与权限决定，不声明 iOS 本地通知。
- 备份为敏感明文 JSON，导入验证 / 预览 / 明确覆盖，失败保留旧记录。数据升级不自动清空。
- PWA Manifest、原创图标、standalone、安全区域、离线外壳和明确更新策略。

## 验收边界

自动化测试、Windows 静态构建和浏览器验收记录见 PWA_REPORT；iPhone 主屏幕、离线冷启动、真实 Safari 持久化、文件导入交接、ICS 实际提醒必须在用户设备实测，不能用桌面模拟替代。
初始用户无健康记录或周期参数。指定样例只用于自动测试和用户主动测试，不默认写入用户库。
