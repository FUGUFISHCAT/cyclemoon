# 月相 Cycle V0.3.0 PRD
日期：2026-11-13。基于 V0.2.0 现有工程升级，不重建。检查点 a82a1c0 / checkpoint/v0.2.0-before-v0.3。

## 目标与发布状态
面向 iPhone Safari / 主屏幕 PWA，Windows 开发，零新增必要支出。保留 Expo、原生 JS 打包和 SQLite / notifications 适配预留。无登录、广告、健康分析或记录上传。
最终最多标记“待真机验收的发布候选版”；未连接真实 iPhone 时不得声称安装、软键盘、离线冷启动或日历提醒实机通过。
公开部署必须由用户明确授权，本次只生成校验后的静态 ZIP，不登录或上传。

## P0 移动体验
- 覆盖 320 / 375 / 390 / 430 CSS px；奶白、紫灰、柔和珊瑚集中在主题变量。
- 五页保留真实数据操作；底部导航和安全区域不遮内容，触控区域约 44×44 以上。
- 日历使用足够宽的网格布局，实际经期、身体记录和预测用文字 / 形状共同区分。
- 经期 / 身体记录使用可滚动弹层；首页提供快速开始 / 结束入口，历史记录仍可编辑删除。
- 日期选择适配 Web；移动输入使用可视视口处理、原生键盘避让；真实 iPhone 键盘仍需手动验收。
- 空状态、加载、提交失败、配额和冲突提示可见；失败保留草稿。

## P0 数据与算法
沿用最近六个有效周期中位数和经验范围，不伪造准确率。审查时区、闰日、跨年、无历史、异常间隔、历史修改及经期冲突。实际记录不等于预测；粗略排卵窗口结合周期不确定性，不能确认排卵或用于避孕。
保存成功以 IDB 事务 complete 为准。经期 ID 稳定，身体日志以日期为稳定自然键；编辑日期视作另一日，不静默移除旧日。
草稿捕获读取 revision；其他窗口保存后拒绝旧草稿覆盖。广播是保存后的可选通知，失败不把已提交的记录说成失败。
保持数据库版本 2 / 内部 snapshot schema 2，避免无必要的破坏性升级。既有 v1 数据补齐默认提醒，未知版本拒绝，不删库重建。增加存储不可用、配额、事务中断和迁移测试。

## P0 JSON 备份
导出格式 schemaVersion 3：app、appVersion、exportedAt、encrypted:false、cycleRecords、dailyLogs、preferences。内部数据结构保持独立。
读取 V0.2 schema 1 / 2 备份；未知未来 schema 拒绝。校验完整结构、日期、重复、冲突、容量及版本字段，先预览再输入明确覆盖确认。提交失败原记录保持；文件明确未加密。
不自动导入测试数据；不把备份、健康日志或密钥打包到公开目录。

## P0 离线更新
内容版本、完整外壳安装、显式应用更新、安装失败继续旧版。Worker 不访问 IDB。
新 Worker 应为仍打开的旧页面提供已缓存旧哈希脚本。只有当前构建确认就绪且无其他窗口时才考虑清理旧外壳，保留回退版本。离线启动仍建立本地 Worker 状态监听，联网后能再次检查更新。
构建检查主屏幕清单、图标、安全区域、五页水合脚本、静态资源及私人文件 / 内容风险。

## P1 提醒与隐私
保留四类 ICS、类型开关、浮动本地时间及 VALARM。显示事件预览与导出说明；相同文件重复导出前提示，明确导入后不会自动更新、不同客户端可能重复，建议独立日历处理旧副本。
支持输入确认后清除本机记录与偏好，通过事务写入空状态、保留 revision，阻止旧标签页复活已清数据。只清理本应用记录，不删除外部备份、日历或其他站点数据。
隐私说明与数据管理入口可访问；持久存储申请不是永不丢失保证；未实现加密、原生通知或云推送不得标为完成。

## 验收
自动检查与桌面浏览器分别报告；有价值测试覆盖周期、失败恢复、备份兼容、事务、迁移、旧 / 新 Worker 兼容、生产构建。
生产 ZIP 根目录包含 index.html；附版本、摘要与产物检查。部署指南包含 HTTPS、路由刷新、更新、回滚和来源迁移。无已知数据丢失缺陷才可进入待真机验收 RC。
