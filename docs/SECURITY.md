# 隐私与安全边界

适用版本：0.3.0，2026-11-13。当前没有声称实现应用级加密、身份认证、远程备份或原生推送。

## 数据流与实际保护

- 记录、备注、症状、周期参数和提醒设置仅存同源 IndexedDB。没有登录、广告、第三方健康分析、API 上传或云同步。选中日期经内存传递，不写入 URL。
- 普通静态访问仍会向托管服务发送请求、IP 等网络元数据；“不上传健康记录”不等于匿名上网。
- 保存以事务 complete 为成功依据，校验 / 版本 / 写入失败保留原快照。无法读取时拒绝用空记录覆盖旧数据。升级只接受已知结构，不自动重建未知库。
- 草稿固定基线 revision，拒绝跨窗口旧草稿覆盖。广播仅传“changed”，不含记录。清除后销毁当前导航下的编辑草稿；其他打开窗口须收到广播或重新聚焦后同步。
- Service Worker 仅缓存编译后的静态应用文件，不访问 IndexedDB；无动态响应、JSON 备份或 ICS 缓存。新缓存 SHA-256 内容核验通过后才能安装，失败保留旧缓存。旧版不可变 JS 可继续访问。
- 静态生产响应配置 CSP：脚本同源和明确内联哈希、禁止外部连接 / 对象 / 嵌框 / 表单提交；React Native Web 样式需要 style-src unsafe-inline。构建将策略写入 dist/_headers，本地服务器也使用全局策略。部署后必须复核真实响应头，不能以文件存在代替线上验证。
- React 文本渲染备注，不使用备注拼接 HTML。应用日志不输出记录和备份。未嵌入第三方脚本。

## 导出、恢复与清除

JSON schemaVersion 3 包含 appVersion、exportedAt、cycleRecords、dailyLogs、preferences，encrypted 固定 false。文件未加密，会暴露完整敏感健康信息。系统文件同步和分享由用户决定；不要上传到公开站点或把备份放进 public、dist、Git。

恢复先校验结构、版本、日期、数量、容量和冲突；显示预览并要求输入“恢复”。按预览时 revision 原子整份替换；失败不清空原库。选新文件即撤销旧预览。兼容旧备份 v1/v2，未来版本或声称加密的文件会拒绝。

清除入口要求输入“清除本机记录”，成功提交空数据并增加 revision，不 deleteDatabase。下载备份、日历副本和其他域名数据不会被清除。该操作不是安全擦除：浏览器、系统快照、磁盘和云端文件副本不受本应用控制。

ICS 默认隐私标题仍含敏感时间信息，导入后可能同步至用户日历账户。稳定 UID 不保证去重，重复导入前处理旧事件。已导入事件不会随本应用变化更新。

## 未实现及剩余风险

1. 无应用级数据库 / 备份加密、口令锁或远程擦除。可访问同一浏览器配置、同源恶意脚本或已解锁设备的人可能读取记录。
2. 持久存储 API 只是向浏览器申请，是否允许由浏览器决定；不能防止手动清理、卸载、设备故障或系统回收。定期离线备份是必要的数据管理步骤。
3. 不自动删除旧外壳缓存，优先兼容挂起页面；长期更新可能增加缓存占用，系统仍可回收。不要用“清除网站数据”来释放外壳空间，因为会一并清除记录。
4. 首次安装未完成、缓存被系统回收时可能无法离线启动。安装失败不声称离线就绪。
5. 未做第三方渗透测试；未连接 iPhone，不能声称 WebKit、主屏幕存储或 iOS 键盘已实测。
6. 原生 SQLite / notifications / 文件接口保留但未实现。原生导出 JS 成功不等于可用的原生健康数据产品。

## 发布与依赖

只上传经校验的 dist 或其 ZIP，不上传项目目录。构建检查常见私人文件名、健康备份 JSON 和私钥文本，Git 忽略备份 / 数据库 / 环境文件；这些不能替代人工审查。依赖兼容性检查与 Expo Doctor 不等同漏洞审计。公开部署前仍需用户明确授权。

原生迁移通过本机 JSON 导入：未来实现原生安全存储后复用 validateData / importBackup 和 Repository，先验证整份数据再在 SQLite 事务中提交；核对记录和提醒后由用户决定是否清理旧 PWA。未来加密应增加真正的密钥管理 / 认证加密与迁移方案，不使用编码或隐藏界面冒充加密。

依据：[IndexedDB 事务](https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction/complete_event)、[持久存储](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist)、[Cloudflare 静态响应头](https://developers.cloudflare.com/pages/configuration/headers/)。

## V0.3.1 补充
文件分享仅在用户发起导出时调用系统分享，由用户选接收位置；AbortError 取消不报告成功，也不自动下载。JSON/ICS没有加密，不要选择不信任的接收者。数据库v3防止旧客户端忽略结束日期待确认状态；未发送云端健康记录。
