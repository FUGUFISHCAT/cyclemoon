## 桌面浏览器验收

使用隔离来源 localhost:4183 或其他未使用端口。不要清除用户正在使用的 localhost:4173 站点。

1. 空状态启动，填入可丢弃的 30 / 5 / 不太规律参数；新增一次合成经期和含中文、emoji、多行的身体记录。
2. 等待“已保存”后刷新、关闭再打开，核对两类记录。保存进行中切勿主动关闭窗口。
3. 分别以 320 / 375 / 390 / 430 CSS px 检查五页无横向溢出，日历格约 44×44 以上，底部导航独立占位；弹层可滚动至提交按钮。
4. 备注聚焦后缩短可视视口，验证滚动和关闭入口；这只是键盘空间模拟，不算 iOS 软键盘通过。
5. 导出 JSON 到本机，修改周期参数，再选择原备份；核对预览、输入“恢复”、确认、等待事务完成、刷新核对。无效文件不得出现可确认的旧预览。
6. 导出 ICS，核对下载文件与提醒时间；重复导出应提示处理旧事件，不保证日历自动去重。
7. 保持同一来源，替换静态版本，检查更新提示，确认后才刷新，核对记录保留。
8. 停止本地静态服务器，关闭旧标签后新开五条已支持路由；离线修改并刷新。此方法验证源站不可达，不等同手机飞行模式或浏览器进程被终止。
9. 清除功能使用合成记录和已下载备份；验证参数与记录归空、旧草稿不再出现，下载文件不受影响。
10. 检查控制台错误，特别是 CSP、React hydration、存储错误。
