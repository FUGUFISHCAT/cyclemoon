## 修好了什么

1. 开放经期进入第15天起首页显著提示核对。点击“今天开始新经期”仍需先明确旧结束日或标记未知、再按确认按钮；取消不写数据，旧首页快捷按钮也不能绕过这一步。未知状态保存为 endPending:true / end:null，不伪造结束日期；记录页可补填。异常超过14天的已结束经期不参与正常经期时长估计，保留原中位数周期算法。
2. JSON/ICS 优先尝试支持 files 的 Web Share API；不支持或非取消错误回退下载。取消分享不会下载或报成功；文案要求用户确认实际保存。继续严格校验 JSON、预览并输入“恢复”才覆盖，未实现加密或自动保护原数据。
3. 审查并保留现有 viewport-fit=cover、根容器和弹层 safe-area-inset、可视视口高度、可滚动弹层及底部导航占位。补充 mobile-web-app-capable。四种 CSS 宽度桌面模拟无横向溢出，导航在视口底部；真实 iPhone inset 和键盘未验证，不为此重构 UI。
4. 设置页加入 Safari/主屏幕/换域名的数据隔离说明和 JSON 迁移步骤；要求核对完成前保留旧站、旧图标和数据。完整流程见 MIGRATION.md。
5. 数据库和 snapshot 从 v2 升到 v3，在原 state 对象存储读取升级，保留 revision、记录 ID、日志及偏好；旧版不能降级打开，避免旧代码忽略新待确认语义。备份文件协议仍为 v3，appVersion 为 0.3.1，兼容导入旧备份；新状态应使用兼容版本恢复，不能随意回滚旧应用。
6. 为不支持无扩展名 HTML 重写的托管服务增加四条路由的目录 index.html，同时保留原 .html 文件。资源、manifest、SW 均为同源根路径；不接 CloudBase SDK 或云数据库。延续标准 ZIP `/` 路径验证。

## 已知限制与下一步

- “结束日期待确认”只表达未知，不确认那段日期真实出血；开始日期仍可用于实际周期间隔估计。没有排卵检测或避孕准确率声明。
- 应用存储/JSON 未加密，系统分享选择的云盘或接收者可接触文件；分享 API 完成也不能替用户确认文件已存妥。
- iPhone 真机能力尚待验收，浏览器持久存储申请不是数据永不丢失保证。
- 新旧域名绝不会自动同步 IndexedDB。迁移核对完成前保留旧网址和独立备份。
- CloudBase 免费环境和默认域名均有限制，不能直接宣称适合长期免费 PWA。结论、官方依据、替代方案及逐步操作见 CLOUDBASE_DEPLOYMENT.md；迁移步骤见 MIGRATION.md。
- V0.4 六项需求仅记录在 V0.4_BACKLOG.md，未实施；没有大规模 UI 改造。
- Node MODULE_TYPELESS_PACKAGE_JSON 和构建 NO_COLOR 提示为非失败警告，未更改 Expo 模块体系以隐藏警告。

先由用户决定域名、免费资格/费用边界并完成 iPhone 清单；明确授权后才能实际托管测试和迁移，当前没有执行任何线上操作。
