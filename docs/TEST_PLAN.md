# 验收计划（0.2.0）

## 自动检查

npm run typecheck；npm run lint；npm test；npx expo install --check；npx expo-doctor；npm run export:web。
测试覆盖空输入、初始参数、不规律、历史中位数、异常间隔、逾期不滚动、未来记录、闰年 / 跨年；ICS 四类事件、时间、开关、隐私、UTF-8 折行、VALARM、稳定 UID；备份完整往返与非法数据；IDB 新实例持久化、事务拒绝 / 并发、v1 升级 / 未来版本保护；SW 缓存失败回退、离线导航、多窗口旧资源保护与缓存清理。

## Windows 浏览器

静态导出后在 localhost:4173：

1. 首次加载五页、设置保存参数、记录经期与身体状态。
2. 页面刷新后记录与参数仍在；选择日历日期后 URL 不带健康日期。
3. 导出 JSON，导出 ICS；预览恢复与明确确认流程。
4. 等离线外壳就绪，停止本地静态服务器后刷新，验证真实离线外壳与记录读取。
5. 离线新增再刷新核对保存；重启服务器、构造新版外壳、检查更新并应用，核对原记录与 schema 未被清除。
   测试仅使用明确标识的合成数据，不把用户真实记录或备份纳入构建目录。
